## Upgrade boundaries

Stop legacy desktop/server and CLI writers before migration. Keep the retained
originals and do not run older writers against converted files. Track sessions
in Git only after migration removes provider tokens from portable records.
Ordinary default-home startup imports `$XDG_STATE_HOME/playbook/sessions`, or
`~/.local/state/playbook/sessions` when XDG is unset, retaining originals in migration receipts.
An explicit home or session directory suppresses that discovery.

Desktop/server hosts require macOS or Linux and private POSIX permissions.
Windows supports the scaffold CLI and browser access to a supported server.

Choose a complete session when both branches changed it; Git does not combine
continuations or undo external effects. Use one device per active session.
Schema 7 does not relocate repository/module paths: different paths allow
history only. Compatible paths still require runtime and effect reconciliation.
